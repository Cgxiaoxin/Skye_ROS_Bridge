# 小臂遥操：频率 / 丢帧 / 大臂 stale / 单电机诊断

默认**左右双臂同录**，日志写在 `scripts/debug/logs/`，终端只每秒一行 Hz，方便重启后对照。

前提：小臂 launch 带 `sync_diagnostics:=true`（Orin 双臂文档已写）；大臂 `skye_robot_driver` 在跑（才有 follower stale 检测）。

---

## 推荐命令（双臂）

```bash
conda deactivate
cd "$(git rev-parse --show-toplevel)"
source skye_ros2_ws/scripts/setup_factr_teleop_env.sh orin
unset FASTRTPS_DEFAULT_PROFILES_FILE

/usr/bin/python3 scripts/debug/record_leader_health.py
# 可选：--duration 120   默认跑到 Ctrl+C
# 可选：--no-follower    只看小臂，不订大臂 joint_states
```

终端示例：

```text
logging -> .../scripts/debug/logs/leader_health_20261102_101500.jsonl
[   1.0s] left js= 458.0Hz max_dt= 2.3ms fl= 250.0Hz age= 4.1ms | right js= 499.0Hz max_dt= 2.1ms fl= 250.1Hz age= 3.8ms
[   2.0s] left js= 124.0Hz max_dt= 8.1ms fl= 249.0Hz age=518.4ms stale=12 | right js= 498.0Hz max_dt= 2.2ms fl= 250.0Hz age= 4.0ms stuck={'ID1': 12}
```

结束会生成：

| 文件 | 内容 |
|---|---|
| `scripts/debug/logs/leader_health_<时间>.jsonl` | `hz_sample` + `js_gap` / `follower_stale` / `diag_*` / `motor_stuck_hint` |
| `scripts/debug/logs/leader_health_<时间>.summary.json` | 全程平均 Hz、max_dt、stale 计数、suspect |

回溯：jsonl 搜 `"kind": "hz_sample"` / `"follower_stale"`。

---

## 怎么读

| 现象 | 含义 |
|---|---|
| 左 ~120、右 ~500 | 左臂总线/该侧负载问题，不是左右代码分叉 |
| 左右都 ~120 | TELEOP + diagnostics / 回调把周期拖慢 |
| `js_gap` / `seq_missing` | 小臂真丢帧或总线卡顿（懒汉） |
| `follower_stale` / `age`>~500ms | 大臂反馈 stamp 相对本机时钟过旧；会触发遥操 `Follower state expired` |
| `suspect_motors` 含 ID1… | 该舵机高电流、速度≈0 |

默认 `follower-max-age=0.50`、`future-tolerance=0.05`，对齐 Orin yaml `runtime.state_timeout` / `future_tolerance`。

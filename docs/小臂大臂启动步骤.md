# P4 · FACTR 小臂 ↔ Skye 大臂（bridge-less）

目标：小臂 Docker 内 `factr_teleop` 与主机 `skye_robot_driver` 对接，**不**再起 `gento_robot_driver`。

## 对齐点（相对旧 launch 的修正）


| 项         | 旧 `start_teleop_m6_dual.launch.py`                | P4 `start_teleop_m6_dual_gento.launch.py` |
| --------- | ------------------------------------------------- | ----------------------------------------- |
| 指令        | `/left                                            | right_joint_control`                      |
| 反馈        | `/left                                            | right_joint_state`（7 轴分侧）                 |
| Docker 挂载 | `marvin_ws` → `/marvin_ws`，`scripts` → `/scripts` | 同左（含 `bind_leader_arms.py`）               |
| 大臂驱动      | `gento_robot_driver`                              | `skye_robot_driver`                       |


小臂 yaml：`follower_joint_offset` 左=0、右=7，与 14 轴 `/gento/joint_states` 一致。

## ROS Domain（固定 21）

同局域网内若有其他遥操测试机使用 `ROS_DOMAIN_ID=20`，FastDDS 组播会把对方的 `factr_teleop` / Marvin 栈扫进本机 `ros2 node list`（出现重名节点、apex 警告等）。

**本套 P4 链路统一用 `ROS_DOMAIN_ID=21`**：vitai 主机、`run_marvin_m6_impedance.sh` 传入 Docker、所有调试终端必须一致。Thor 若参与 ROS 通信，同样设为 21。

换 domain 或重启节点后建议：

```bash
export ROS_DOMAIN_ID=21
ros2 daemon stop; ros2 daemon start
```

干净图期望：`/skye_robot_driver` + `/factr_teleop_left` + `/factr_teleop_right` 各 1 个，无重名警告。

## QoS


| Topic                               | skye_robot_driver           | 说明                           |
| ----------------------------------- | --------------------------- | ---------------------------- |
| `/gento/joint_states`               | **RELIABLE** KeepLast(1)    | 供 FACTR sync 订阅（默认 Reliable） |
| `/gento/{left,right}_joint_control` | **BEST_EFFORT** KeepLast(1) | 可接收 FACTR Reliable 发布        |




## 启动顺序



### 1) 主机：大臂驱动

```bash
cd /data/coding/tianji/Skye_ROS_Bridge
export ROS_DOMAIN_ID=21
unset ROS_LOCALHOST_ONLY
export RMW_IMPLEMENTATION=rmw_fastrtps_cpp
./scripts/start_skye_for_factr.sh
# 另开终端确认（同样 export ROS_DOMAIN_ID=21）：
source skye_ros2_ws/install/setup.bash && export ROS_DOMAIN_ID=21
ros2 topic hz /gento/joint_states
ros2 service call /gento/set_mode skye_robot_driver/srv/SetMode "{mode: 2}"
```



#### 模式联调

（调试终端先 `export ROS_DOMAIN_ID=21`）

1. 切换到同步模式：
  ```bash
  ros2 topic pub --once /mode/switch_sync std_msgs/msg/String "{data: switch_sync}"
  ```
  - 观察 `/teleop/state` 状态变化：`TELEOP_SYNCING` → `SYNCED`
2. 切换到 TELEOP 模式：
  ```bash
  ros2 topic pub --once /mode/switch_teleop std_msgs/msg/String "{data: switch_teleop}"
  ```
  - 进入 TELEOP 后，可继续通过 `ros2 topic hz /gento/left_joint_control` 或 `right_joint_control` 检查话题流



### 2) Docker：小臂

```bash
ROS_DOMAIN_ID=21 ./scripts/run_marvin_m6_impedance.sh
```

容器内：

```bash
source /marvin_ws/install/setup.bash
export ROS_DOMAIN_ID=21 ROS_LOCALHOST_ONLY=0 RMW_IMPLEMENTATION=rmw_fastrtps_cpp

# 换臂后先绑定串口（见 docs/新主臂串口绑定.md）
# python3 /scripts/bind_leader_arms.py && source /marvin_ws/.skye/leader_arms.env

# FTDI 低延迟（按实际 ttyUSB；bind 脚本也会写 1）
echo 1 | sudo tee /sys/bus/usb-serial/devices/ttyUSB0/latency_timer
echo 1 | sudo tee /sys/bus/usb-serial/devices/ttyUSB1/latency_timer

# 必须用 gento remap 版 launch（不要用旧 start_teleop_m6_dual.launch.py）
ros2 launch factr_teleop start_teleop_m6_dual_gento.launch.py use_keyboard:=false
# 若 share 未同步，可用绝对路径：
# ros2 launch /marvin_ws/launch_overlay/start_teleop_m6_dual_gento.launch.py use_keyboard:=true
```



### 3) 键盘

## 图检查（主机）

```bash
export ROS_DOMAIN_ID=21
ros2 node list | grep -E 'skye_robot_driver|factr_teleop'
ros2 topic info -v /gento/joint_states
ros2 topic info -v /gento/left_joint_control
```

期望：`joint_states` 有 skye Publisher + 两个 factr Subscription；  
`left/right_joint_control` 有 factr Publisher + skye Subscription。

**小臂节点：**


| **Topic**                                    | **含义**                                             |
| -------------------------------------------- | -------------------------------------------------- |
| `/leader_arm/current_state`                  | 小臂关节状态（7 轴 rad）                                    |
| `/teleop/state`                              | 模式：`IDLE` / `TELEOP_SYNCING` / `SYNCED` / `TELEOP` |
| `/left_gripper/state` `/right_gripper/state` | 夹爪反馈                                               |
| `/gento/left                                 | right_joint_control`                               |
| `/gento/joint_states`                        | 大臂 14 轴反馈（主机 driver 在才有）                           |
| `/mode/switch_*`                             | 模式切换                                               |

```bash
# 检查左右夹爪状态
ros2 topic echo --once /left_gripper/state
ros2 topic echo --once /right_gripper/state

# 大臂反馈（确认 skye 在发）
ros2 topic echo --once /gento/joint_states
```



## 不要做

- 主机与 Docker 使用不同的 `ROS_DOMAIN_ID`（会互相看不见）
- 与同 LAN 其他测试机共用 domain 20（会扫进对方节点，出现两套 `factr_teleop_*`）
- 同时启动 `gento_robot_driver` 与 `skye_robot_driver`
- 使用未 remap 的 `start_teleop_m6_dual.launch.py`（会订错反馈 topic）
- 把 `scripts/` 挂成 `/marvin_ws`（旧 bug，已修）

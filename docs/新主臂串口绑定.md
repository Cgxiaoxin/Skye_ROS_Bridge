# 换主臂：自动绑定串口

**`ROBOT_PROFILE` 须与日常启动 / sync 一致**（Thor=`thor`，Orin=`orin`）。绑定写 `marvin_ws/configs/<profile>/grav_comp_m6_*.yaml`；`sync_marvin_overlay.sh` 从同一 profile 目录同步到 install。Orin 上电后先：

```bash
export ROBOT_PROFILE=orin
```

小臂 Docker 内运行（`scripts/run_marvin_m6_impedance.sh` 已挂载 `/scripts` 并传入 `ROBOT_PROFILE`）：

```bash
# 两臂都插好上电；无 factr 占串口
pgrep -af factr_teleop || true

export ROBOT_PROFILE=orin   # Thor 可省略或 =thor
python3 /scripts/bind_leader_arms.py
# 正好 2 路：按提示拔【左臂】USB 识别左右
# >2 路：交互选 left/right index

source /marvin_ws/.skye/leader_arms.env   # 当前 shell 立即生效（必须）
export ROS_DOMAIN_ID=21 ROS_LOCALHOST_ONLY=0 RMW_IMPLEMENTATION=rmw_fastrtps_cpp
```

写入位置：

- `marvin_ws/.skye/leader_arms.env` / `leader_arms.yaml`（gitignore）
- `grav_comp_m6_{left,right}.yaml` 的 `dynamixel_port`

预览不写盘：`python3 /scripts/bind_leader_arms.py --dry-run`

**注意：**

- 拔插 USB 后 `latency_timer` 会复位；脚本结束会自动写 `1`。若仍报 latency，手动：

```bash
echo 1 | sudo tee /sys/bus/usb-serial/devices/ttyUSB0/latency_timer
echo 1 | sudo tee /sys/bus/usb-serial/devices/ttyUSB1/latency_timer
```

- 旧容器需重新 `./scripts/run_marvin_m6_impedance.sh` 才会挂载 `/scripts` 并读到最新绑定。
- 绑定后务必 `source`，或 exit 后重进容器（run 脚本会自动 source `.skye/leader_arms.env`）。

## 一键关闭各臂伺服使能

先 `source /marvin_ws/.skye/leader_arms.env`（托住小臂，会下落）。

```bash
pgrep -af factr_teleop || true

python3 - <<'PY'
from dynamixel_sdk import *
import os
for side, key in [("left", "ROBOT_LEADER_DYNAMIXEL_PORT_LEFT"),
                  ("right", "ROBOT_LEADER_DYNAMIXEL_PORT_RIGHT")]:
    name = os.environ[key]
    PORT = name if name.startswith("/") else f"/dev/serial/by-id/{name}"
    pk = PortHandler(PORT); pk.openPort(); pk.setBaudRate(4000000)
    ph = PacketHandler(2.0)
    for i in range(1, 9):
        ph.write1ByteTxRx(pk, i, 64, 0)
        print(f"{side} disabled {i}")
    pk.closePort()
PY
```

## 命令式遥操（1 sync → 等稳 → 2 teleop）

前提：主机 `skye_robot_driver` + Docker 内 `start_teleop_m6_dual_gento.launch.py` 已起；`ROS_DOMAIN_ID=21`。

大臂建议先确认阻抗模式：

```bash
# 主机
source skye_ros2_ws/install/setup.bash && export ROS_DOMAIN_ID=21
ros2 topic hz /gento/joint_states --window 100   # 期望 ~250 Hz（夹爪开启时也应保持）
ros2 service call /gento/set_mode skye_robot_driver/srv/SetMode "{mode: 2}"
```

小臂侧用 topic 切模式（比键盘更稳、可脚本化）：

```bash
# Docker 内或主机同 Domain 均可（须 export ROS_DOMAIN_ID=21）
export ROS_DOMAIN_ID=21
ros2 topic pub --once /mode/switch_stop  std_msgs/msg/String "{data: switch_stop}"
sleep 1
ros2 topic pub --once /mode/switch_sync  std_msgs/msg/String "{data: switch_sync}"
# 托住双小臂，等同步完成后再继续
sleep 2
ros2 topic pub --once /mode/switch_teleop std_msgs/msg/String "{data: switch_teleop}"
sleep 1

# 查询遥操状态：必须 data: TELEOP（否则还在 SYNC / 其它态）
ros2 topic echo /teleop/state --once \
  --qos-durability transient_local --qos-reliability reliable
```

| Topic | 作用 |
|-------|------|
| `/mode/switch_stop` | 停主手输出（等价键盘 `3`） |
| `/mode/switch_sync` | 小臂跟大臂 `/gento/joint_states`（等价 `1`） |
| `/mode/switch_teleop` | 发 `/gento/{left,right}_joint_control`（等价 `2`） |
| `/teleop/state` | Transient Local；期望 `TELEOP` |

### 关于 `factr_apex_adapter` 使能

Thor / Apex 链路才需要：

```bash
ros2 service call /factr_apex_adapter_left/set_enabled  std_srvs/srv/SetBool "{data: true}"
ros2 service call /factr_apex_adapter_right/set_enabled std_srvs/srv/SetBool "{data: true}"
```

**当前 Skye P4（bridge-less）不跑 apex adapter**：`factr_teleop` 直连 `/gento/*` + `skye_robot_driver`。图上没有 `/factr_apex_adapter_*/set_enabled` 是正常的；确认 `/teleop/state == TELEOP` 且 `/gento/*_joint_control` 有流量即可。

### 夹爪（无独立节点）

夹爪桥挂在 **`/skye_robot_driver` 同进程**（`enable_gripper: true`），不是单独 ROS 节点。  
CAN 读超时 `gripper_feedback_timeout_ms` 默认 **1ms**（过长会把单线程 executor 卡住，关节反馈掉到 ~9 Hz）。

| Topic | 方向 |
|-------|------|
| `/left\|right_teleop_gripper/ctrl` | FACTR → skye（指令）。`gripper_invert:=true`：扳机 1=开 0=闭 |
| `/left\|right_gripper/state` | skye → FACTR（反馈，同样按 invert 回到扳机语义） |

接线：左 ARM0+ID1，右 ARM1+ID2。电机 0=开 1=闭，`gripper_close_limit=0.93`。
右小臂 `joint_signs[7]` 须为 +1（与左一致），否则 TELEOP 默认闭合。

检查：

```bash
ros2 topic info -v /left_gripper/state
# Publisher: skye_robot_driver；Subscription: factr 侧
ros2 topic info -v /left_teleop_gripper/ctrl
# Publisher: factr 侧；Subscription: skye_robot_driver
ros2 topic hz /left_gripper/state --window 50    # 期望 ~100 Hz
ros2 topic hz /gento/joint_states --window 100   # 夹爪开启时仍应 ~250 Hz
```

# 双臂启动遥操

本流程用主机包 `skye_factr_teleop`，**不需要 Docker / `marvin_ws` 小臂**。  
旧流程（`run_marvin_m6_impedance.sh`、`Thor_Orin_遥操启动.md`）才进容器。

串口已写在 Thor 配置里（左 `FTBEO9L1`、右 `FTBEO8WL`），**日常不用每次 bind**；换机/换 FTDI 才改 yaml 或换 `robot_profile:=orin`。

---

## 每个终端先做（一行）

```bash
source /data/coding/tianji/Skye_ROS_Bridge/skye_ros2_ws/scripts/setup_factr_teleop_env.sh
```

会设置 `source`、`ROS_DOMAIN_ID=73`、以及 `DRIVER_CONFIG` / `LEFT_CONFIG` / `RIGHT_CONFIG`。

---

## 启动（两个 launch）

| 终端 | 命令 |
|---|---|
| A 大臂 | `ros2 launch skye_robot_driver skye_robot_driver.launch.py robot_profile:=thor "params_file:=$DRIVER_CONFIG"` |
| B 双小臂 | `ros2 launch skye_factr_teleop start_teleop_m6_dual.launch.py robot_profile:=thor sync_diagnostics:=true` |
| D 控制 | 见下（不要在 A/B 发命令） |

`robot_profile:=thor` 时会自动用包内 `grav_comp_m6_{left,right}.yaml`，**一般不用再传** `left_config` / `right_config`。  
Orin 改成 `robot_profile:=orin` 即可。

启动后两侧仍是 **IDLE、力矩关闭**。

---

## 同步 → 遥操（终端 D，托住双小臂）

`/mode/switch_*` 一次作用左右两侧。

```bash
ros2 topic pub --once /mode/switch_sync std_msgs/msg/String '{data: switch_sync}'
# 两侧都 SYNCED 后：
ros2 topic pub --once /mode/switch_teleop std_msgs/msg/String '{data: switch_teleop}'
# 静止 5～10 s，再慢动
```

可选自检 / 看状态：

```bash
ros2 topic echo --once /gento/left_joint_states
ros2 topic echo --once /gento/right_joint_states
# ros2 topic echo /teleop/state --qos-durability transient_local
```

---

## 停止（托住双小臂）

```bash
ros2 topic pub --once /mode/switch_stop std_msgs/msg/String '{data: switch_stop}'
ros2 service call /gento/hold_current std_srvs/srv/Trigger '{}'
```

## 和旧 Docker 流程对比

| | 旧（Docker） | 现在（reboot） |
|---|---|---|
| 小臂 | `./scripts/run_marvin_m6_impedance.sh thor` + 容器内 launch | 主机 `skye_factr_teleop` |
| Domain | 常 `21` | 约定 `73` |
| USB | 常要 `bind_leader_arms` / sync overlay | Thor yaml 已写死 by-id；换臂再改 |
| 代码目录 | `marvin_ws` + 镜像内 `factr_teleop` | `skye_ros2_ws/src/skye_factr_teleop` |

**先别删** Docker / `marvin_ws` 相关文件：Operator UI、HITL、`Thor_Orin_遥操启动.md` 仍依赖旧路径。日常手启遥操可只用本文；等 UI 切到 reboot 包再清理。

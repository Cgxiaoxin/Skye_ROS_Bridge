每个终端先做：

```bash
cd /data/coding/tianji/Skye_ROS_Bridge/skye_ros2_ws
source /opt/ros/humble/setup.bash

# Thor 本机用 20；Orin 用 21（或: source .../setup_factr_teleop_env.sh thor|orin）

DRIVER_CONFIG="$PWD/src/skye_robot_driver/config/skye_robot.yaml"

```

---

## 启动

| 终端 | 角色 | 命令 |
|---|---|---|
| A | 大臂 | `ros2 launch skye_robot_driver skye_robot_driver.launch.py robot_profile:=thor "params_file:=$DRIVER_CONFIG"` |
| B | 左小臂 | `ros2 launch skye_factr_teleop start_teleop_m6_left.launch.py robot_profile:=thor "left_config:=$CONFIG" sync_diagnostics:=true` |
| D | 控制 | 见下（不要在 A/B 发命令） |

---

## 同步 → 遥操

都在 **D** 操作，托住小臂。

1. `switch_sync`：`IDLE → … → SYNCED`  
   （小臂使能、跟上大臂；还不给大臂发命令）
2. 确认 `SYNCED` 稳定后再 `switch_teleop` → `TELEOP`  
   （开始发 `/gento/left_joint_control`；大臂 relative 跟随）
3. 先静止观察 5～10 s，再小幅慢动左小臂

```bash
ros2 topic pub --once /mode/switch_sync std_msgs/msg/String '{data: switch_sync}'
# 另开窗口可看：
# ros2 topic echo /teleop/state --qos-durability transient_local

ros2 topic pub --once /mode/switch_teleop std_msgs/msg/String '{data: switch_teleop}'
```

TELEOP 后小臂 J8（扳机）会映射到大臂末端夹爪（`/left_teleop_gripper/ctrl`）。
若启动时报 FTDI `latency_timer ... expected 1`，先把对应 `ttyUSB*` 设为 1 再启小臂。

---

## 停止

托住小臂。

```bash
ros2 topic pub --once /mode/switch_stop std_msgs/msg/String '{data: switch_stop}'
# 确认 /teleop/state → IDLE 后，大臂受控保持：
ros2 service call /gento/hold_current std_srvs/srv/Trigger '{}'
```
